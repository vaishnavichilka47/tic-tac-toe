# Tic-Tac-Toe 🎮

A simple and interactive Tic-Tac-Toe game built using **HTML, CSS, and JavaScript**.

## Features

* Two-player gameplay
* Detects winning combinations
* Detects draws
* Reset game option
* Simple and responsive interface

## Technologies Used

* HTML
* CSS
* JavaScript
